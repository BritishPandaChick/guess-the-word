# Guess the Word game website
Bonus project from Skillcrush updated 102 course in 2021

## Tech Stack
* HTML
* CSS
* JavaScript

## Instructions
1. Clone this repo or download the zip file. 
2. Open index.html in your browser. 
3. Type a letter in the white box to make a guess what the mystery word is.
4. Press the guess button to see if your guess is correct.
